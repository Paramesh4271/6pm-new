Maven is a build automation tool and a software project management tool, primarily used for Java-based projects. It helps manage project builds, documentation, reporting, dependencies, and more by using a Project Object Model (POM) and standard conventions. Maven also facilitates the distribution and release of software projects. 
A branch in Git is simply a lightweight movable pointer to one of these commits. The default branch name in Git is master . As you start making commits, you're given a master branch that points to the last commit you made. Every time you commit, the master branch pointer moves forward automatically. Note.
